# fabrikant: Egress-Allowlist (Default-Deny-Proxy, ADR 0051)
#
# Domains that agent containers (sandbox network `fabrikant-sandbox`) may reach
# through the proxy. Subdomains are included. One domain per line
# (hostname with at least two labels; `com` or IP addresses are rejected),
# `#` comments allowed. Without an entry here the proxy allows NOTHING
# (default deny). The builtins (github.com — incl. `api.github.com` via
# subdomain matching —, models.dev) are added on top —
# see `egress.BUILTIN_ALLOWLIST`.
#
# Typical additions (model providers):
# huggingface.co
# inference.example.com
#
# Self-hosted GitLab (ADR 0062): host of the GitLab instance the project uses
# (API + clone). github.com is a builtin; a custom GitLab host must be added
# here, otherwise the default-deny proxy blocks agent access.
# gitlab.example.com
#
# Python packages (`uv lock`/`uv sync`; read-only, uv verifies hashes):
# pypi.org
# files.pythonhosted.org
